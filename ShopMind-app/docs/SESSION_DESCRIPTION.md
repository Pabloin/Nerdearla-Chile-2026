# ShopMind: Construye un asistente de compras en la nube

## Descripción Corta (para el formulario)
Construye un asistente de compras en AWS con AgentCore, MCPs y Kiro

## Descripción Completa

¿Quieres ver cómo construir un asistente de compras inteligente que realmente funciona? En esta sesión práctica, construiremos ShopMind: un personal shopper que usa múltiples agentes especializados trabajando en paralelo para ayudar a los usuarios a encontrar productos dentro de su presupuesto.

### Lo que verás en vivo:

- **Amazon Bedrock AgentCore**: Orquestación de agentes en contenedores aislados con observabilidad completa
- **Model Context Protocol (MCP)**: Integración de herramientas externas (búsqueda web, comparación de precios, reviews)
- **Kiro AI IDE**: Desarrollo asistido por IA para acelerar la construcción del proyecto
- **Arquitectura multi-agente**: Supervisor + herramientas especializadas colaborando en tiempo real

### Demo en vivo:

Verás un panel mostrando 4 agentes trabajando simultáneamente:
- 🔍 Búsqueda de productos
- 💰 Comparación de precios  
- ⭐ Análisis de reviews
- 📊 Validación de presupuesto

Todo con trazabilidad completa en CloudWatch y memoria persistente entre sesiones.

### Tecnologías:

- Amazon Bedrock (Nova Pro)
- AgentCore Runtime & Gateway
- FastMCP para servidores MCP
- Strands Agents framework
- React + FastAPI
- AWS Lambda

### Nivel: 200 (Intermedio)

Ideal para desarrolladores que quieren aprender a construir aplicaciones de IA generativa con arquitecturas de agentes en AWS.
